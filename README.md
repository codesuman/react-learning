# React Learnings

## USE STATE HOOK

Manages state within a functional component.

When normal variables undergo change they won't affect how the component behaves particularly what they render. 

`useState` is a React Hook that lets you add a state variable to your component. When a stateful variable undergoes changes - Virtual DOM gets updated.
